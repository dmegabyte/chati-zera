# Windows: машинные особенности

Машинный оверлей: только то, что отличается на вашей машине. Заполните под себя.

## Пути

- Конфиг: `C:/Users/<user>/.config/opencode`
- Данные OpenCode: `C:/Users/<user>/.local/share/opencode`
- Оболочка: PowerShell (pwsh). Команды Linux выполняются через `wsl -e bash -lc "..."`.

## MCP

Перечислите здесь свои MCP-серверы и что они дают. Например: браузер, база знаний, документация.

## Если MCP-поиска нет

Порядок тот же, меняется только вход:

1. `read` / `grep` / `glob` по локальным файлам и документации;
2. `webfetch` / `websearch` по внешним источникам;
3. ваши собственные MCP-инструменты, если настроены.

Правило source reference сохраняется: каждый вывод подтверждается путём к файлу,
ссылкой или выводом инструмента.

## Ограничения

- Секреты лежат вне репозитория; в конфиг подставляются через `{env:...}` или `{file:...}`.
- Опасные и необратимые действия выполняются только после явного подтверждения.
