# Linux/WSL: машинные особенности

Дополнение к общим `AGENTS.md`, `core-rules.md` и `chati-style.md`. Заполните под свою машину.

## Пути

- Конфиг: `~/.config/opencode`
- Данные OpenCode: `~/.local/share/opencode`
- Оболочка: bash. Команды Windows выполняются через `powershell.exe -NoProfile -Command "..."`.

## MCP

Перечислите здесь свои MCP-серверы и что они дают. Например: поиск по документации,
локальная память, трекер задач.

## Если MCP-поиска нет

Порядок тот же, меняется только вход:

1. `read` / `grep` / `glob` по локальным файлам и документации;
2. `webfetch` / `websearch` по внешним источникам;
3. ваши собственные MCP-инструменты, если настроены.

Правило source reference сохраняется: каждый вывод подтверждается путём к файлу,
ссылкой или выводом инструмента.

## Ограничения

- Секреты лежат в `secrets/` (каталог в `.gitignore`) или в переменных окружения.
- Опасные и необратимые действия выполняются только после явного подтверждения.
