# Настройка под себя

Репозиторий задаёт рамку. Всё, что зависит от машины, аккаунта и проектов, живёт локально.

## Модель

По умолчанию `opencode-go/deepseek-v4.1-flash`. Поменять:

```jsonc
{
  "model": "openai/gpt-6.1-terra"
}
```

Или точечно для роли — строкой `model:` в её файле:

```yaml
model: openai/gpt-6-luna
```

## Свой MCP-сервер

```sh
opencode mcp add mydocs --global --url https://example.com/mcp
```

Правила менять не нужно: они не перечисляют конкретные серверы. Если сервер даёт поиск
по документации, агент использует его наравне с локальными файлами.

Секреты не пишите в конфиг:

```jsonc
"headers": { "Authorization": "Bearer {env:MY_TOKEN}" }
```

## Своя роль

1. Создайте `agents/my-role.md`.
2. Добавьте frontmatter:

```yaml
---
description: что делает роль и когда её звать
mode: subagent
model: openai/gpt-6.1-terra
permission:
  read: allow
  edit: deny
---
```

3. Ниже — текст инструкции: вход, выход, границы.
4. Проверьте: `opencode api get /api/agent` — роль должна появиться в списке.

Права дочерней роли не наследуются. Если роль должна только читать — запретите `edit`, `bash`
и `subagent` явно.

## Своя процедура

```text
skills/my-skill/SKILL.md
```

Минимальный файл:

```markdown
---
name: my-skill
description: когда применять этот скилл
---

# My Skill

1. Проверь состояние.
2. Сделай ограниченное изменение.
3. Проверь результат и отчитайся.
```

Скиллы подгружаются по требованию, поэтому описание должно честно говорить, когда скилл нужен.

## Локальный слой

Два файла, которых нет в репозитории:

- `opencode.jsonc` — модель, MCP, права, политики.
- `AGENTS.local.md` — пути, оболочка, доступные MCP, машинные ограничения.

Шаблоны лежат в `templates/`. Скрипт `scripts/bootstrap.*` создаёт файлы из шаблонов
и не перезаписывает существующие.

## Секреты

- Только `{env:VAR}` или `{file:path}` в локальном конфиге.
- Каталог `secrets/` уже в `.gitignore`.
- Токены не передаются субагентам и не попадают в отчёты.

## Проверка после изменений

```sh
opencode api get /api/agent        # роли загрузились
opencode mcp list                  # MCP подключены
opencode run "Ответь: OK"          # сквозная проверка
```

Если роль не появилась — проверьте frontmatter: незакрытый `---`, неверный `mode`
или опечатка в имени файла.
