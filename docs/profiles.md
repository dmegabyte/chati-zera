# Режимы: CHATI, ZERA или оба

Слои независимы. Можно поставить только ассистента, только принцип ZERA или всё вместе.

| Режим | Что активно | Кому подходит |
|---|---|---|
| `both` (по умолчанию) | правила + `ЧАТИ` + `executor` + ZERA | полный набор |
| `chati` | правила + `ЧАТИ` + `executor`, без ZERA | нужен только ассистент с границами |
| `zera` | ZERA + кардинальное правило + скилл `zera-cleanup`, без персоны | нужен принцип и уборка структуры |

## Переключение

```sh
python3 scripts/profile.py chati
python3 scripts/profile.py zera
python3 scripts/profile.py both
```

Команда идемпотентна: можно вызывать сколько угодно раз, в любом порядке.

## Что именно меняется

| | `both` | `chati` | `zera` |
|---|---|---|---|
| `instructions` | `ZERA.md`, `chati-style`, `AGENTS.local` | `chati-style`, `AGENTS.local` | `core-rules`, `ZERA.md`, `AGENTS.local` |
| `AGENTS.md` | загружается | загружается | переименован в `AGENTS.chati.md` |
| `agents/` | включён | включён | переименован в `agents.off` |
| `skills/` | включён | переименован в `skills.off` | включён |
| Скилл `zera-cleanup` | доступен | недоступен | доступен |

Выбранный режим записывается в `.profile`. Обратное переключение возвращает каталоги
на место — данные не удаляются.

`core-rules.md` подключается только в режиме `zera`: там `AGENTS.md` отключён, и правило
«факт без источника не факт» иначе пропало бы. В `both` и `chati` это правило уже есть
в конституции, раздел 3.

## Что остаётся нетронутым

- `opencode.jsonc` — сохраняются модель, MCP и права; меняется только блок `instructions`.
- `AGENTS.local.md` — машинные настройки.
- `docs/`, `templates/`, `scripts/` — не зависят от режима.

## Если установка была копированием в конфиг

Репозиторий как рабочая папка конфига поддерживает переключение сразу. Если вы копировали
файлы вручную, скопируйте `scripts/profile.py` рядом с конфигом либо повторите копирование
нужного набора по таблице выше.

## Проверка после переключения

```sh
opencode api get /api/agent     # в chati/both есть ваши роли, в zera — только встроенные
ls agents skills 2>/dev/null    # выключенные каталоги имеют суффикс .off
```
